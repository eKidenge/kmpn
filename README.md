# KMPN

**Kenya Masters and PhD Network (KMPN)** is a Django-based platform that connects Master's and PhD students, researchers, alumni, and academic institutions across Kenya.

## Features

- User registration and profiles
- Research communities
- Discussion forums
- Events management
- Scholarships and job opportunities
- Resource sharing
- Newsletters and notifications
- Membership and payment management

## Tech Stack

- Python
- Django
- SQLite (development)
- Bootstrap
- HTML, CSS, JavaScript

## Installation

```bash
git clone https://github.com/eKidenge/kmpn.git
cd kmpn
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
